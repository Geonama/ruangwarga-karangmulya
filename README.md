# RuangWarga Karangmulya

Website untuk Evaluasi 2 Cloud Computing dengan domain Sistem Pelayanan Publik Desa/Kelurahan.

## Isi website

- Pengajuan surat administrasi.
- Pengaduan masyarakat.
- Upload dokumen atau foto pendukung.
- Tracking status tiket.
- Antrean admin sederhana.
- Backend API Node.js untuk ECS.
- Integrasi PostgreSQL RDS dan S3 upload saat dijalankan di AWS.

## Cara membuka

Buka `index.html` langsung di browser untuk mode lokal, atau jalankan:

```bash
npm install
npm start
```

Lalu buka `http://localhost:3000`.

Untuk deployment AWS, ikuti [AWS_STEP_BY_STEP.md](AWS_STEP_BY_STEP.md).
